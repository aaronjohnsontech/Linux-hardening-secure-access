# Security and Sanitization Notes

This repository is a sanitized portfolio version of a lab project. It intentionally avoids publishing real credentials, production system names, sensitive hostnames, or private environment details.

## Published Safely

- Placeholder IP addresses and usernames
- Sanitized command examples
- Documentation templates
- Validation and rollback checklists
- Example scripts requiring review before use

## Not Published

- Real credentials
- Private keys
- Production network details
- Sensitive logs
- Client or employer data

## Responsible Use

Do not apply firewall or SSH hardening changes to systems without authorization and recovery access. Test in a lab environment first.
